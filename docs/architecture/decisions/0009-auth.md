# ADR 0009: Trusted identity mapping and repository-wide RBAC

- Status: Accepted
- Context: Agent role claims are forgeable unless bound to authenticated workloads and accountable principals.
- Decision: The transport authenticates an agent and maps it to one v1 role while retaining a separate principal; centralized repository-wide RBAC authorizes every catalog operation.
- Rejected: Roles inside request bodies; reviewer-as-approver; anonymous local trust; component grants before a use case exists.
- Consequences: Only requirements-manager mutates or decides; other roles validate drafts without side effects.
- Security effects: Token/credential verification, least privilege, and decision-time checks are mandatory; break glass is offline.
- Migration impact: Fine-grained grants may be additive only after denial precedence and audit semantics are defined.
